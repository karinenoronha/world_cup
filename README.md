# FIFA World Cup Analytics Dashboard 

An interactive data analysis of FIFA World Cup history using Python and Streamlit.

## Insights explored:
- Which teams play the most matches
- Relationship between participation and titles
- Historical performance trends
- Goal scoring evolution over time

## Tech Stack:
- Python
- Pandas
- Plotly
- Streamlit

## Key Insight:
More matches ≠ more titles. Consistency matters more than dominance.
